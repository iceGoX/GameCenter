# GameCenter · 五款游戏

沿用「明亮潮玩」原生安卓设计：奶油底色、青柠操作按钮、立体游戏封面。五款游戏按五子棋、角斗士棋、中国象棋、飞行棋、黑白棋排序；单列滚动，不增加账户、导航栏或原生房间功能。

## Pixso 交付

文件名：`GameCenter · 明亮潮玩 · 五款游戏`。包含 `01 · Ardot 原稿迁移` 与 `02 · 五款游戏扩展` 两页；原稿页 9 个画板，扩展页 8 个画板（含组件区）。原稿页保留原有 8 个状态及规范，新卡片重建为 10 个本地组件（每款游戏的已配置 / 未配置各一个），大厅使用组件实例。

Pixso 不提供原稿所用的 PingFang SC / Inter 完整字重，因此迁移文字明确映射为思源黑体 CN 的 Regular / Medium / Bold。正文仍可编辑；Android 保持系统 sans-serif。Ardot 原文件保留不变。

## 可编辑源稿与预览

- `legacy-screens.json`：从原 Ardot 设计包提取的八个页面状态及组件规范，保留文字、尺寸、颜色、图层、矢量图标与封面引用。
- `five-games-screens.json`：新增的五游戏大厅、Demo 未配置大厅、设置列表、三款游戏的网站编辑及滚动视口。
- `preview.html`：读取上述源稿的浏览器预览。在仓库根目录运行 `python3 -m http.server 8874 --bind 127.0.0.1`，打开 `/docs/design/preview.html`。长画板用于查看全部内容，实际手机通过滚动展示。

图层结构迁移不等同于跨工具完整工程转换：文字与图形可继续编辑，新增卡片组件已在 Pixso 重建；原 Ardot 的变量绑定、其余组件关系和自动布局约束没有原样迁移，保留的是计算后的视觉尺寸与层级。旧稿保留用于比对，新稿单独维护。

## 页面与交互

| 页面 | 顶部与主要内容 | 操作与滚动 | 底部 |
| --- | --- | --- | --- |
| 大厅 | 系统状态区、品牌与设置、介绍、五款游戏卡片 | 每卡独立进入或设置网站，整页单列滚动 | 简短说明，系统手势安全区 |
| 未配置大厅 | 与大厅相同，卡片显示尚未设置 | “设置网站”打开对应游戏编辑页；部分已配置时其入口立即可用 | 配置提示与安全区 |
| 网站设置 | 返回、标题、五个设置项与配置状态 | 每行进入对应编辑页，整页滚动 | 默认与自定义说明，安全区 |
| 网站编辑 | 返回、游戏标题、对应目录示例、HTTPS 字段 | 保存/取消；无效地址保留输入与错误说明；避让键盘 | 留空恢复默认或 Demo 未配置说明 |
| 加载/失败/退出 | 沿用原有状态并显示当前游戏名 | 重试、返回、继续游戏；保留退出后果提示 | 系统安全区 |

基准宽度 390；内容左右间距 20；卡片 350 × 216，圆角 24，间隔 16；主操作 136 × 48。新增设置行底色分别为浅沙、浅蓝、浅绿。系统区域示意为 62/24，实际 App 使用系统 Insets。

## 封面与代码对应

封面由 ImageGen 按原五子棋封面的构图延展：左侧留白承载标题与按钮，右侧展示游戏元素；导出 WebP 至 Android 的 `drawable-nodpi`。象棋参考原木红帅黑将，飞行棋参考四色飞机与骰子，黑白棋参考网站的芭乐与青提棋子。图片中的棋盘是装饰封面，不承担规则说明。

`Game.kt` 统一维护游戏 ID、标题、描述、封面、设置行底色、示例目录与变体默认地址。两个版本共用大厅、设置、网站编辑和 WebView。新游戏默认 URL 只放在忽略的本地 Store 配置中；公开模板只用 `example.com`。

设计预览不能证明设备运行、联机同步或完整离线首启。设备验收按开发指南执行。
